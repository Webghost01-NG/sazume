# Security policy

Do not report vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository when available, or contact the maintainers through GitHub's private channels. Include the affected version, reproduction steps, and impact; do not include real credentials or private keys.

Sazume's reference code is not a security audit or production payment integration. Do not use the fixtures to custody real funds. Mainnet execution is disabled in the current Arc qualification adapter.
